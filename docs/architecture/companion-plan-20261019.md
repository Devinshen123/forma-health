# Forma 伙伴养成实施方案

依据用户提供的 Instagram reel DeoTnV0B6Il 完整讲解，核心为健康行为驱动宠物成长、装扮、宝箱、好友竞争。2026-10-19 用户要求准备方案、实现并上线，允许真实 Claude Code 协作。本方案不采用视频品牌角色、资产或第三方代码；Forma 原创 SVG 植物伙伴。最新授权将原先不做社交的范围扩展为自愿加入的双人邀请码挑战，不增加公开社交网络。

## 用户体验

今日页增加伙伴卡：等级、成长进度、今日三项任务，进入独立成长页面查看角色、换装、免费里程碑宝箱和七日好友挑战。沿用现有饮食、训练、睡眠记录与双语、移动端五项导航，不整体重写网站。新账户从 0 XP 起步；演示模式清楚标注且不请求私人接口。

上线后新保存一份饮食、一次训练（或自行确认休息日）、一次睡眠分别获得 10 XP。奖励不按卡路里、重量、时长或睡眠长短计算，不改变健康建议，不扣生命或惩罚漏记。XP 明确只代表游戏进度。每个 UTC 日每类最多一次，共 30 XP；同一档案本地日同类也最多一次，防跨 UTC 午夜重复。只对服务器保存事务第一次观察到、日期等于当时档案时区今天的事实结算，旧事实先登记基线，不信任客户端 createdAt。换时区、claim、编辑、删除重建和历史补录不追溯奖励。

每累计 3 个有奖励的 UTC 日解锁一个免费宝箱，服务器保存开启结果；外观按固定目录轮换，无付费或随机消费。已领取奖励不会因为编辑或删除事实而重复发放；移除健康记录仍按原流程执行，奖励历史保留在独立账本，可导出或随账户删除。

双人挑战由一方创建随机邀请码，另一方主动加入；创建当日起七个 UTC 日只显示双方加入后有奖励的参与天数（每日最多 1），不分享饮食、睡眠、训练、身份邮箱或健康指标。用户加入前明确知道对方能看到累计参与天数，不能据此推断没吃或没运动。任一方可退出、废止邀请码；并列视为共同完成，没有健康排名。到期结果保留 48 小时，可关闭或重新创建，已结束挑战隐藏邀请码。

## 实现契约与验证

共享类型为 src/companion.ts。服务器所有的独立 SQLite 表通过 owner 外键隔离并级联删除；奖励按 owner + UTC day + quest + rule version、owner + local day + quest 及源身份防重，健康保存 save/sync/saveWorkbench 内原子登记 seen-facts 并结算。API 在既有会话、X-Forma-Account 绑定、同源写请求校验之后注册。GET /api/companion；POST /api/companion/claim（空 body，只返回服务器已结算快照，不从旧状态补扫）；POST /api/companion/rest；POST /api/companion/chests/:id/open；PUT /api/companion/equipment {item: catalog-id|null}；POST /api/companion/challenges {action: create|join|leave, code?:string}。所有修改返回 CompanionSnapshot，客户端不能提交 XP/等级/所有者。导出包含自己的伙伴、账本和挑战参与信息，不包含其他人的记录。

验收包括实际 HTTP 身份隔离、重复请求/新 mutation 重放/编辑删除重建/工作台投影/并发开箱/未拥有装备/邀请码隐私/退出与账户删除，真实浏览器双语、手机布局、键盘、演示、空账户和错误状态；减少动态静态检查，不声称真机验证。睡眠沿用记录自身 sleep.timezone 的醒来日与当前该时区日期比较，服务器时钟确认已经醒来；额度仍按 UTC/profile local 日。界面可见时每 15 秒静默 GET，前台操作优先并取消过期背景读取；不因健康数组引用变化自动 POST/反复播报。真实 Claude Code 独立只读评审，明确记录是否实际执行和结果，不冒称调用。

WHOOP/Oura OAuth、HealthKit 不在此网站首版实现，也不显示为已连接；原生 App 可后续复用同一服务器契约。本轮不调用付费 AI。正式公网服务需 Node 24+、持久 SQLite/私有上传及授权媒体存储、HTTPS、备份；用户现有服务商尚待确认。开发、构建、测试和 GitHub 提交先完成，不将 localhost 或临时隧道冒称正式上线。
