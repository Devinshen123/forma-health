# Forma 网站设计规格

临时产品名 Forma，名称商标可用性尚未核查。视觉参考是本项目新生成的 dashboard-concept.png 和 mobile-meal-concept.png；未声称实际浏览过 Cal AI App。

基底锁定：冷灰 #f7f8fa，白 #ffffff，正文 #171b20，灰 #737985，薄边框 #e9ecf0，主色 #c5f467。桌面 210px 左栏，主内容二列（主区+280–340px周趋势侧栏），24px间距；移动端单列与底部五项导航。圆角16px，主要CTA圆角12px。字体 system-ui、-apple-system、BlinkMacSystemFont、Segoe UI、PingFang SC、Microsoft YaHei。正文15px，标题32px/650，hero28px/650，指标32px/600；中文不负字距。Lucide outline，1.7px，20–24px。

首屏允许文案：Forma、今日/Today、饮食/Nutrition、训练/Training、睡眠/Sleep、趋势/Trends、报告/Reports、设置/Settings；把状态，练成习惯。／每一天，都有适合你的下一步。；演示数据·体验完整流程／创建我的计划；今天，保持你的节奏。／训练、饮食与休息，一起向前。／查看今日计划；饮食摄入/训练时间/昨晚睡眠；今日安排/最近饮食/本周节奏；让计划跟着你调整／由你确认，随时撤销。

示例数值仅演示模式显示，真实新账户是空状态，缺失显示—。手机版示例文案/数值以桌面设计与真实数据规则为准，忽略生成图自己添加的营养目标数字。所有额外表单遵循相同系统，功能所必需的状态文案允许扩展并记录。

动效用于按钮按下、sheet显隐和导航选中；尊重减少动态。所有表单、登录、空/错误/保存状态、键盘focus、dialog焦点、手机溢出均需验证。
