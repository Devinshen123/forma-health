# WEB-DATE-01：统一首页与趋势的视图日期

2026-11-04；决策/实现者01 lead；用户委托本人更新主线并安排修改。基线main/7017064。

问题：首页使用浏览器日而趋势使用档案日，同一账户在跨日的两个时区可能展示不同记录；趋势把本地化显示格式当机器键，异常时区可抛错。

方案：保持既有Vite/React/Express架构和localDate(date)调用兼容，新增可选timeZone；新增视图时区解析和7/14日窗口纯函数。有效档案时区优先，缺失/无效回退有效浏览器时区，再回退UTC。日期键固定Gregorian/ASCII YYYY-MM-DD，由formatToParts组成。窗口从同一个now和末日派生，UTC中午只作日历步进与标签载体。两页均使用共享函数，首页星期标签也用UTC锚点。首页文案明确最近7天。

取舍：保留两页独立算法会持续漂移；整体重写所有记录日期/聚合或安装日期库超出修复范围。因此只替换两页消费者，其他localDate调用维持浏览器默认语义。不改已保存的记录日期、睡眠时区/时间戳或旧行动完成键；新行动按统一视图日写入。页面重渲染后重新计算，不承诺长驻午夜自动刷新。

验收：固定LA/Shanghai相反组合、同区、无效/缺失时区、UTC最后回退、DST正反/月年闰日、7/14窗口首尾；实际两页中英渲染、未记录—/已知0、行动保存捕获及原记录不变。本人验证与独立审查分开报告；候选先push本人分支，不直接合main。
