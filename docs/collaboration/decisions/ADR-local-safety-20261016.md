## 行为

- 私有 API 的账号头校验绑定到匹配的路由，不再依赖大小写/尾斜杠敏感的字符串白名单。附件 GET/HEAD 使用会话推导 owner，以支持浏览器图片与下载；不能读取其他账户文件。
- 保存函数捕获渲染时账号、会话代次和引擎；旧编辑器不能借用新账户引擎。全部业务子树按账号/会话重建，异步完成通知也检查代次。同步面板和业务 Fragment 使用不同的 key 前缀，避免反复登录留下旧 DOM。
- 同账户重新登录保留原队列和 mutationId；切换账户后的内存引擎暂存，返回原账号时恢复。未启用离线存储的队列仍只在本页内存，离开页面会警告；刷新前应同步、显式启用离线存储或导出文字记录。
- 恢复暂存引擎前先合并持久队列、settled 和授权 generation。已被其他标签放弃的删除不会复活。停止/恢复会轮换运行代次，旧的在途身份验证或响应不能在新生命周期继续发请求。另一标签首次授权持久化时，原先从未持久化的内存队列会迁入缓存；已撤回的旧代次不能迁入。
- 附件一旦提交给保存就保守保留；超时、网络失败、取消和卸载都不会清理可能被本机队列引用的文件。尚未提交的上传仍可清理。结果不确定时可能留下未引用文件，本轮不做自动垃圾回收，以免误删待同步附件。
- 饮食、报告、睡眠草稿在打开时固定 ID/createdAt；响应丢失后的原表单重试按当前记录 ID 更新，不重复追加。同步比较忽略对象字段顺序，保持数组顺序与实际字段值变化的含义，避免服务器规范化对象顺序后产生无效版本。
- 睡眠只修改感受时保留原 ISO 时刻及隐藏秒数，包括回拨后的第二次本地时刻。新填/改动的重复时刻及跳时缺口会明确拒绝，不擅自选择某次重复时刻。
