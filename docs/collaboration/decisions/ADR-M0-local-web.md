# ADR-M0：先交付本机网站，公开邀请前改造共享服务

2026-10-13。人类后续明确要求“你先把网做出来”，覆盖早期开发前文件中的实现待批准闸口；不是根据笼统权限推断授权。没有批准付费服务或生产发布。月订阅意向US$20，Mac+iPhone已有，Apple会员状态未知（不能把未提及等同已确认未加入）。

接受本机Claude独立评审关于资源接口、增量同步、服务端规则、auth_identities及云端认证的建议，列为公开邀请/跨端接入前的M1任务。当前M0使用快照API＋revision，只作单机体验；没有offline outbox、HealthKit批量上云、Apple OAuth或邮件验证，明确不充当双端产品底座。

营养记录当前保存用户填写的referenceGrams对应基准值，不把照片模型估计作为事实；摄入按grams/referenceGrams确定性计算，服务端校验输入和来源。M1的共享聚合将由服务端完成，不接受客户端总量作为权威统计。现有固定缩短训练候选是显式用户操作，不冒充可审计服务端健康规则。

“Apple登录＋邮箱”没有规定邮箱必须密码或OTP。M0密码仅本机演练，未验证邮箱；真实托管阶段推荐一次性验证码/链接与独立身份表，需核查发信条件后实施，保留UI而替换认证与数据层。固定开发端口当前只启动一份共享服务，自动测试API可在独立临时目录/随机端口运行；下一阶段可配置端口，但不是公开部署的许可。

FudAI可提取的原生纯逻辑/审核视图优先在iPhone阶段评估；采用前登记精确路径、SHA、修改与第三方许可。无健康分数；未知营养值不填0；授权不明的训练图片不复用。

角色建议：Codex维持总体契约与集成；Claude可承担明确范围的服务端规则和独立QA。没有向活跃Claude会话暗中派发代码任务，当前仅通过共享请求回复协商。供应商、地区、医学内容、上传同意与预算仍待决定，现有静态或工具文件不能代替人类决定。
