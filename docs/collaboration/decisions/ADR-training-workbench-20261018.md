## 身份与完整数据

- 私有 API 为 `/training-workbench/api/{me,config,data,data/rev,media/...}`。所有请求用 HttpOnly Forma cookie，加固定 `X-Forma-Account` 与服务端账户核对；写请求还检查 Origin。查询参数只固定本页归属，不能用来认证。
- 当前完整文档以 `{state,stamped,baseRev,baseWid}` CAS 提交，响应 `{state,rev,wid,warnings}`；不接受空对象清空数据。只为计划字段追加历史版本，删除的训练事实/照片不藏在计划历史中。
- 每账户独立私有媒体，验证 SHA、类型/大小、图像解码及像素上限，总量配额。导出包含工作台原记录、计划历史和媒体；删除 Forma 账户同时删除服务端与本机该账户缓存。
- 浏览器存储统一前缀 `forma-workbench:<uuid>:`，所有可用存储门面必须替换并验证成功，否则不加载应用。每个文档重新确认 `/me` 后才能显示缓存事实；退出/切换账户的根控制事件立即锁住已开的工作台，即使断网。保留未同步副本供原账户重新登录恢复。

## Forma 汇总与边界

完成的训练由确定性投影转为 Forma Workout，保存与原记录在同一事务。次数/负重未知保留 null；真实不足一分钟的训练保留小数；单侧、热身、递减和 rest-pause 按实际事实处理。不兼容内容完整保存并返回 warnings，不以零或编造时长填充。稳定账户/来源身份避免重复导入；投影被原生端改动时拒绝静默覆盖。

原生 Progress 将投影记录交回工作台管理。成功保存仅向同源父窗口通知事件与账户 ID，父窗口检查来源后刷新汇总。进行中训练可在当前浏览器恢复，不冒充已完成训练。

网站保留计划/轮转、收藏、自定义动作/器械、组数/计时/进度、历史与肌群统计、围度/体重/进步照/对比、备份和导出等训练功能。独立账户/管理、未配置的 AI 聊天与供应商、原生 Health/Android/推送配对、条码签到不开放；不显示自创健康或疲劳分数。source 自己的 SW 禁用，Forma SW 只缓存公开构建文件，绝不缓存私有 API 或上传媒体。减少动态时动画需用户手动播放。
