# 独立审查报告模板

任务ID、审查者身份/会话、日期、实际checkout/分支、BASE/HEAD或精确差异：

需求和计划来源、审查范围、独立于实施者的说明：

## 实际检查

逐项列执行者、完整命令、退出码/结果与证据；区分静态、实际执行、他人报告及历史证据。保留失败，不把未测写通过。

## 发现与复验

每项写严重度、具体文件位置、复现、预期/实际、影响、修复owner和复验条件。修复后记录新HEAD、实际结果及关闭/未关闭依据。

## 两项结论

- 需求符合性：通过 / 阻塞 / 未验证；依据：
- 代码质量与安全：通过 / 阻塞 / 未验证；依据：
- 未验证及剩余风险：
- 当前候选是否具备本任务上传条件（不自动授权main合并或部署）：

审查者不得修改产品替实现者修复；自测、联署或旧SHA证据不替代独立结论。
