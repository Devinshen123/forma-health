# 任务交接模板

- 正式TASKS ID、执行者身份/实际会话、唯一writer确认：
- 实际checkout、分支、BASE SHA、对应远端最新SHA及核实时间：
- 需求/批准方案与既有决定来源：
- 唯一可写文件；只读文件/交接冻结：
- 输入/输出接口、依赖与不可改变的约束：
- 具体目标与可观察的正反/失败验收：
- 原失败、复现步骤、环境（如平台/系统/设备）：
- 验证命令、预期结果、合成数据与未测边界：
- 独立审查者、审查包和报告路径、复验要求：
- 当前Git上传/合并/部署限制：

本模板填写具体任务内容，不维护第二套任务状态；不得带密钥/健康记录。子任务只接收必要上下文，不复制主管整段历史。
