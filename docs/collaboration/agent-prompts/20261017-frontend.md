# Forma 当前聊天 frontend 接手

你是当前聊天的前端子代理，合并 shell + features。先读 AGENTS.md、TASKS.md 顶部的新所有权表、已有 features 状态、发给 shell/features/frontend 的请求、docs/design/design-system.md。新建你自己的 status/frontend.md，保留其他角色状态。

任务 CO-02 只做接手盘点：阅读真实 App、主要业务页面、i18n、同步调用边界；记录结构、真实已实现能力、尚未实现能力、最多五项具体风险和建议下一任务。发现问题附路径和行号，区分确定缺陷与待验证假设。不修改产品源码；不安装依赖、不启动服务、不调用真实AI、不更改其他目录。qa统一运行基线构建和测试，你引用其结果须明确来源，不能称自己运行。

权限以TASKS为准；types/api/engine等契约属于lead，storage属于backend，领域函数本轮只读，tests属于qa。越界需求写请求。不再派生代理或发消息到其他聊天。结束更新frontend状态，报告可接手情况及阻塞；按AGENTS仅提交自己新建的状态和请求，提交以[frontend]开头。不要git add -A，不要删除git锁；共享索引冲突可稍后重试。
