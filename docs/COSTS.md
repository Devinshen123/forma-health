## AI 情景公式

2026-10-14新增食物照片接口，用户选择先接入、稍后配置密钥。本轮尚无真实供应商调用费用。固定gpt-5.4-mini-2026-03-17的公开价输入US$0.75/百万、输出US$4.50/百万；最长1024像素图片约≤1229计费patch token，加固定短提示与schema，输出≤2000 token、reasoning=none。每次调用预留US$0.02是保守应用记账，实际费用须看供应商账单，价格变化要复核。[模型和价格](https://developers.openai.com/api/docs/models/gpt-5.4-mini)、[图像token规则](https://developers.openai.com/api/docs/guides/images-vision)。

每用户默认10次识别/UTC日、一次在途、5次/分钟；每日US$0.40，项目总额US$2/日，包含一次可选重试。失败占预算，SQLite原子检查两级限额，重启或删账号不退项目已预留额。不覆盖同一API项目其他应用调用，也不是已选择的运营月预算；尚未建立月总额控制。正式邀请前仍须确定整体服务费和供应商项目限额。

`月成本 = Σ(输入token/1,000,000 × 输入价 + 输出token/1,000,000 × 输出价 + 工具费用) × 重试系数`。图片token受分辨率/模型影响，推理token可能计入输出，OCR按页增量，不能固定承诺“每张多少钱”。供应商、模型、地区与健康数据处理条件需在接入前确定；模型价格参见 [OpenAI 官方 API 定价](https://developers.openai.com/api/docs/pricing)。不使用已被官方标为 deprecated 的模型作为新产品默认。
